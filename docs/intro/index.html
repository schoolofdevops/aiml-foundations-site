AI & ML Foundations: Machine Learning, LLMs & AI Agents

Hands-on Generative AI & Agentic AI foundations — build an AI agent, RAG & a capstone. Your gateway to MLOps. — by Gourav Shah, School of DevOps & AI.

A from-scratch, hands-on foundations course for technical professionals entering AI/ML — and the Level-1 gateway into the MLOps, LLMOps, and Agentic DevOps paths. Start by placing ChatGPT, Claude and agents on one AI Map, learn the living vocabulary of modern AI, then build the real thing lab by lab: a first ML prediction, a neural-net digit classifier, a first LLM API call, an AI agent with tools, RAG over your own PDF, and a model served behind an API — culminating in a capstone AI assistant you run, break, and show off. Every classical idea is taught only because it explains the AI the learner uses today (the Relevance Contract). Modern throughout: reasoning models, prompt/context engineering, prompt injection. A companion evergreen 'Frontier' track keeps the course current — new engineering disciplines (context, harness, loop engineering), the agent ecosystem (MCP, agentic IDEs), and the three career paths — and grows as the field moves. Optimized for engagement and completion: a lab every core module, quizzes and coding exercises throughout, interactive simulators, and per-module deep dives.

Who this is for​

Technical professionals — developers, DevOps/cloud engineers, and career-changers — who use AI daily and want to understand and build it. No machine-learning background assumed; basic Python and command-line comfort is enough. Examples are deliberately domain-neutral (not DevOps-specific) so the course serves the whole tech audience while remaining the Level-1 on-ramp to the MLOps, LLMOps, and Agentic DevOps paths.

How to use this course​

Each module is a Lesson (concepts + analogies + diagrams), a Lab (copy-runnable, validated live), and a Quiz. Work them in order; the project spine — One growing artifact: a document-savvy AI assistant. Each core lab adds a capability — predict (ML regression), classify (neural net), call an LLM, reason as an agent with tools, retrieve over a chosen PDF (RAG), and serve behind an API — and the capstone stitches them into an end-to-end assistant the learner runs, breaks, and shows off. — grows across modules into the capstone.
